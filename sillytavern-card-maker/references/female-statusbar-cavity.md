# 女主状态栏：腔内差分图与外部世界书兼容

适用：女性主角卡的状态栏里，用「断面图 / 腔内图」表现正常、排卵、危险期、受精、妊娠、临盆、精液少/中/多、插入等状态。  
也适用于把已有的 A/B 差分图改成单图、或让状态栏读取外部独立世界书的多套状态词。

---

## 1. 先定展示模型：单图优先，不要默认拆腔

用户说「子宫和小穴改成独立腔内」时，先分清两种需求：

| 需求 | 做法 | 代价 |
|---|---|---|
| 只是要不同状态各有一张图 | **单图全断面**：一个视口 + 一个状态下拉 | 最低，推荐默认 |
| 真的要分别看子宫腔 / 小穴腔 | 两个视口或两个裁切区 + 两套状态 + 宫颈口判定 | 高，容易规则打架 |

实测结论：

- 多数用户要的是「**一张图里能看不同状态**」，不是两个独立面板。
- 拆成双腔后，用户很可能下一轮就说「合在一起展示，不要区分具体子宫还是阴道」。
- 所以：**没有明确要求独立判定时，先做单图全断面**；只有用户明确要「子宫腔插入 / 小穴腔插入分开判定」才拆。

拆腔时也必须遵守：

- `体内精液` 的 ml 只能有一个权威源，不要同时维护 `子宫.精液ml` 和 `体内精液.宫腔ml` 两套。
- 子宫腔与小穴腔的插入/精液判定要明确「宫颈口」这个闸门，否则模型会把普通性交写成进入子宫。
- 一旦用户说不要区分，**立刻回到单腔模型**，不要保留两套并行判定。

## 2. 素材盘点：先做状态 × 插入矩阵

拿到图包先盘点，不要边写 UI 边猜：

```text
状态：标准状态 / 排卵期 / 危险期 / 受精 / 妊娠 / 临盆 / 精液中 / 精液少 / 精液多
变体：未插入 / 插入
=> 9 × 2 = 18 帧
```

要点：

1. 每张图都要有稳定的 `id`，例如 `B_精液多_插入`。
2. 源文件命名与 id 分离：文件名可以是中文，id 用固定 ASCII/中文混合，但必须可预测。
3. 检查 `尺寸 / 模式 / alpha / 背景色`：
   - 透明背景：直接打包。
   - 白底：从边框做 flood fill 去白。
   - **黑底**：从边框做 flood fill 去黑（阈值约 60~70），不要用「全图变黑为透明」，会吃掉内部深色描线。
4. 图片内容贴边是常态；**不要靠裁切解决边框遮挡**，用视口留白（见 §4）。

### 2.1 确保每张图都被使用

做一个纯函数测试，不要靠肉眼：

```js
const bases = ['标准状态','排卵期','危险期','受精','妊娠','临盆','精液少','精液中','精液多'];
for (const base of bases) {
  for (const inserted of [false, true]) {
    const expected = `B_${base}${inserted ? '_插入' : ''}`;
    const got = uterusPick({
      怀孕: {是否怀孕: base === '妊娠' || base === '临盆'},
      体内精液: {总ml: ({精液少:10, 精液中:50, 精液多:200})[base] || 0},
      腔内: {状态: base, 是否被插入: inserted}
    }).id;
    if (got !== expected) throw new Error(`${expected} -> ${got}`);
  }
}
```

18 个组合全过，才叫「每张图都用上」。  
下拉列表也必须列出这 18 个，而不是只列其中一部分。

## 3. 状态归一：外部世界书不会只说你的 9 个词

外部独立世界书可能写「正常、发情、易孕、着床、怀孕、分娩、内有精液、大量精液、灌满、溢出」等，不要要求它改成你的枚举。  
做法是**合并读取 + 关键词归一 + 回退**。

### 3.1 合并读取多个字段

```js
const stateParts = [
  cav['状态'], cav['外部状态'], cav['状态文本'], cav['描述'],
  cav['子宫'] && cav['子宫']['状态'],
  cav['小穴'] && cav['小穴']['状态'],
  sex['当前状态'], sex['状态'], sex['腔内状态'], sex['腔状态'],
  sex['精液状态'], sex['子宫状态'], sex['小穴状态'], sex['宫内状态'], sex['阴道状态'],
  ej['状态'], ej['精液状态'], ej['描述'], preg['阶段']
].map(uterusText).filter(Boolean);
const stateText = stateParts.join(' ');
```

数值也做兜底：

```js
const total = num(ej['总ml']) || (num(ej['阴道ml']) + num(ej['宫腔ml']))
  || num(cav['精液ml']) || num(sex['精液量']);
```

### 3.2 别名表

| 归一键 | 可识别写法 |
|---|---|
| 标准状态 | 正常 / 标准 / 普通 / 干净 / 日常 / 平静 / 无异常 |
| 排卵期 | 排卵 / 排卵期 / 发情 / 卵泡 / 求偶 |
| 危险期 | 危险 / 危险期 / 易孕 / 受孕窗口 |
| 受精 | 受精 / 着床 / 受孕成功 / 已受精 |
| 妊娠 | 妊娠 / 怀孕 / 孕早 / 孕中 / 孕晚 / 怀胎 / 有孕 / 孕期 |
| 临盆 | 临盆 / 分娩 / 临产 / 足月 / 产程 / 生产 |
| 精液少 | 精液少 / 少量精液 / 残留少 / 有精液 / 内有精液（量未知时） |
| 精液中 | 精液中 / 中等精液 / 适量精液 / 精液较多 / 精液残留 |
| 精液多 | 精液多 / 大量精液 / 大量内射 / 灌满 / 满溢 / 溢出 / 浓精 / 精液过量 |
| 插入 | 插入 / 抽送 / 性交 / 交合 / 抽插 / 挺入 / 顶入 / 正在进入 |

**关键区分**：

- `内射` 是事件，不是「当前仍插着」；不要因为看到「内射」就选 `_插入` 图。
- `插入 / 抽送 / 性交中` 才是 `_插入`。
- `精液多 / 大量 / 灌满` 优先于普通「精液」；但妊娠 / 临盆 / 受精优先于精液量。
- 状态文本说「排卵期」但仍有大量精液：选精液图，把排卵写进 reason；不要为了用排卵图而隐藏精液。

### 3.3 推荐优先级

```text
怀孕 / 临盆
  > 临盆词
  > 受精 / 着床
  > 精液量（文本明确 + 总ml阈值）
  > 排卵
  > 危险期
  > 标准
```

回退：**怀孕 → 精液量 → 是否插入 → 标准状态**。  
未知状态不要报错、不要阻断变量更新；把原文放进 `reason`，选最接近的图。

### 3.4 纯函数签名

```js
function uterusPick(sex) {
  // 只读变量，不写 DOM、不写变量
  return { id: 'B_精液中', reason: '...' };
}
```

渲染函数只消费 `{id, reason}`；这样 18 帧测试可以脱离 DOM 跑。

## 4. 图片显示：边框不能压图

### 4.1 不要用 `border` 做内框

`border` 占内容盒，图片铺满时边框线会直接压在图上，尤其图片本身是紧裁切时非常明显。

错误：

```css
.viewport { border: 1px solid gold; overflow: hidden; }
```

正确：

```css
.viewport {
  border: 0;
  box-shadow: 0 0 0 1px rgba(212,175,55,.5), 0 2px 8px rgba(62,39,35,.1);
  overflow: hidden;
}
```

再用 JS 留出内衬：

```js
const gutter = narrow ? 4 : 6;
vp.style.width  = frameW * scale + gutter * 2 + 'px';
vp.style.height = frameH * scale + gutter * 2 + 'px';
img.style.left  = -f.x * scale + gutter + 'px';
img.style.top   = -f.y * scale + gutter + 'px';
```

- 外圈 `box-shadow` 画在盒子外面，不会盖住图片。
- `gutter` 是图片与描边之间的空隙；桌面 6px，窄屏 4px。
- 不要用 `outline` 代替：圆角/裁剪时表现不稳定。
- 如果图片内容本身被源素材裁掉（例如子宫顶部缺失），那不是边框问题；需要更大原图或重绘，不能靠 CSS 补。

### 4.2 精灵图偏移

固定 cell + `map.json`：

```js
img.style.width  = spriteW * scale + 'px';
img.style.height = spriteH * scale + 'px';
img.style.left   = -f.x * scale + gutter + 'px';
img.style.top    = -f.y * scale + gutter + 'px';
```

所有帧尺寸一致最稳；如果混用不同尺寸，必须逐帧记录 `w/h` 并单独算视口，不能共用固定 cell。

## 5. 窄屏适配：按宽度，不按 UA

不要用 `/Android/` 判断；桌面窄窗口、安卓、平板、iframe 宽度都可能不同。

```js
function isNarrow() {
  try { return matchMedia('(max-width: 600px)').matches; }
  catch (e) { return innerWidth <= 600; }
}
```

- 窄屏图片按 `0.5` 缩放，同时缩放视口、图片宽高和偏移。
- `stage.minHeight` 同步减半，否则图片缩小后留下大块空白。
- 600px 是实测可用的断点；如果卡只在手机用，480 也可以，但不要太窄（很多 iframe 是 500+）。
- 用 `@container` 处理布局，用 JS 处理精灵图尺寸；两者不要互相打架。

## 6. 判定：单腔就统一，拆腔才分闸门

### 6.1 单图 / 单腔（推荐默认）

- 精液统一按 `总ml` 结算；`阴道ml`/`宫腔ml` 只保留旧版兼容。
- 受孕：`有内射 + 排卵期/危险期`，不区分具体腔室，不设宫腔ml门槛。
- 状态字段只负责选图与叙事，不替代 `体内精液` / `怀孕`。

### 6.2 拆腔（只有用户明确要求时）

- `腔内.子宫` / `腔内.小穴` / `腔内.宫颈口` 三块。
- 普通插入只进小穴腔；子宫腔插入必须 `宫颈口=开放` 且正文明确「穿过宫颈/突入子宫」。
- 小穴腔内射只增加 `阴道ml`；只有宫颈口开放 + 扶她 ≥200ml 或明确宫腔灌注，才把约 10% 转入 `宫腔ml`。
- 受孕只看 `宫腔ml>0` + 排卵/危险期。
- `处女`：小穴腔首次被插入即 false；器具经小穴腔进入子宫腔也 false；人工宫腔灌注不改变处女膜状态。

**不要在单腔版里保留拆腔判定**；用户说「不要区分」时，规则、变量、UI 三处一起回到单腔。

## 7. 与 MVU 强制更新协议配合

外部「变量强制更新 4.0」类世界书通常是**审计层**，不是 schema：

- 不要原样导入 12K 的通用协议；它包含技能/任务/成就/势力等本卡不存在的模块，且每轮输出全量审计报告会挤掉正文。
- 做成**卡专用精简协议**：
  - 独立常驻条目 `[mvu_update]变量强制更新协议（卡名）`；
  - 只列本卡模块（世界/资产/产业/人员/主角/腔内等）；
  - 引用 `[mvu_update]变量更新规则` 作为唯一字段来源；
  - 输出 `<UpdateVariable><BianLiang>…</BianLiang><Analysis>…</Analysis><JSONPatch>…</JSONPatch></UpdateVariable>`；
  - 无变化输出 `[]`；
  - 首轮全量审计，之后只对缺失/占位/命中字段写操作。
- 不要启用通用模板里的「映射表」占位条目；它会让模型写不存在的路径。
- 输出格式条目要同步加 `<BianLiang>`，否则协议要求了但模型没有位置写。

## 8. 女主状态栏其它高频同步

- **自省标题**：不要硬编码「女男爵」。优先 `getUserName()`，降级 `substituteParams('{{user}}')`，再降级字面量 `{{user}}`。
- **年龄**：从 Persona / 角色档案模板的「年龄」字段同步；只在当前年龄仍是默认 24/空值时覆盖，避免剧情年龄增长后被重置。
- **窄屏**：图片缩放、stage 高度、toolbar 换行要一起改；只缩图片会留下大空白。
- **术语**：UI 标题、按钮、下拉、caption、reason、JS 内部 key 要同时改；只改标题会出现「子宫腔」按钮配「小穴腔」图。

## 10. 常见坑

| 症状 | 原因 | 处理 |
|---|---|---|
| 图片被金色边框压住 | `border` 在内容盒内 | 改外圈 `box-shadow` + gutter |
| 图片缩小后下面一大块空白 | 只缩图片，没缩 stage 高度 | narrow 时 stage min-height 同步减半 |
| 18 张图只用了几张 | 只按枚举匹配，没按插入/精液量分支 | 建 9×2 矩阵 + 纯函数测试 |
| 外部世界书写「发情」不显示 | 只认「排卵期」 | 加别名 + 合并读取多字段 |
| 内射后错误显示插入图 | 把「内射」当成「插入」 | 插入词只收 插入/抽送/性交/交合/抽插/挺入/顶入 |
| 状态栏显示「正常」但图是精液 | 精液量优先于状态词 | 文本明确精液量优先；否则按总ml阈值 |
| 子宫/小穴拆开后规则打架 | 两套 ml/两套插入判定 | 回到单腔，或只保留一个 ml 权威源 + 宫颈口闸门 |
| 强制更新协议每轮输出巨长 | 原样导入 12K 通用协议 | 做卡专用精简协议，引用变量更新规则 |
| 安卓/桌面缩放不一致 | 用 UA 判断 | 用 `matchMedia('(max-width:600px)')` |
| 自省标题还是「女男爵」 | 硬编码 fallback | `getUserName()` → `substituteParams('{{user}}')` → `{{user}}` |
